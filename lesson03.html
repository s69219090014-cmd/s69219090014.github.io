บทที่ 3 การสร้างเว็บไซต์ด้วย HTML5

3.1 พื้นฐานภาษา HTML5

HTML5 (Hypertext Markup Language) เป็นภาษาที่ใช้สร้างโครงสร้างเว็บไซต์ โดยบอกเว็บเบราว์เซอร์ว่าข้อมูลส่วนใดเป็นหัวข้อ ย่อหน้า รูปภาพ หรือองค์ประกอบอื่นๆ เพื่อให้แสดงผลได้ถูกต้อง

HTML5 รองรับสื่อมัลติมีเดีย เช่น วิดีโอและเสียง และมี Semantic Tags ที่ช่วยให้ระบบค้นหา (SEO) และ Screen Reader เข้าใจโครงสร้างเนื้อหาได้ง่ายขึ้น

3.1.1 โครงสร้างไฟล์มาตรฐาน

โครงสร้างมาตรฐานของเอกสาร HTML5 ประกอบด้วยส่วนสำคัญ ได้แก่ <!DOCTYPE html>, <html>, <head> และ <body>

3.1.1.1 การประกาศ <!DOCTYPE html> และการเปิดแท็ก <html>

ต้องประกาศ <!DOCTYPE html> ไว้บรรทัดบนสุด เพื่อบอกเบราว์เซอร์ว่าเอกสารนี้ใช้มาตรฐาน HTML5 จากนั้นใช้ <html> ครอบโค้ดทั้งหมด และสามารถกำหนดภาษา เช่น <html lang="th">

3.1.1.2 การกำหนดรายละเอียดใน <head> และ <title>

แท็ก <head> ใช้เก็บข้อมูลเชิงเทคนิค เช่น การตั้งค่าภาษา การเชื่อมต่อ CSS และข้อมูลสำหรับ Search Engine ส่วน <title> ใช้กำหนดชื่อที่แสดงบนแท็บของเว็บเบราว์เซอร์

3.1.1.3 การจัดการเนื้อหาหลักภายใน <body>

แท็ก <body> ใช้บรรจุเนื้อหาที่ต้องการให้ผู้ใช้งานเห็นและโต้ตอบ เช่น หัวข้อ ข้อความ รูปภาพ วิดีโอ และปุ่มต่างๆ

ตัวอย่างการแบ่งเนื้อหาด้วย <div>

เมื่อเว็บไซต์มีข้อมูลจำนวนมาก สามารถใช้ <div> เพื่อแบ่งกลุ่มเนื้อหาให้เป็นสัดส่วน เช่น ส่วนหน้าร้านและส่วนติดต่อ

โครงสร้าง HTML5 แบบ Semantic

HTML5 มี Semantic Tags ที่ช่วยสื่อความหมายของส่วนต่างๆ ได้ชัดเจนกว่า <div> ทำให้โค้ดเป็นระเบียบและช่วยให้คอมพิวเตอร์กับระบบค้นหาเข้าใจโครงสร้างเว็บไซต์ได้ดีขึ้น

3.2 การใช้งาน Tag และ Attribute

แท็ก (Tag) ใช้สื่อสารกับเว็บเบราว์เซอร์ โดยแท็กส่วนใหญ่ประกอบด้วยแท็กเปิดและแท็กปิด ส่วน Attribute คือคุณสมบัติเสริมที่ใส่ในแท็กเปิด เช่น การกำหนดสี ขนาด ตำแหน่ง หรือปลายทางของลิงก์

3.2.1 แท็กจัดการข้อความ

การเลือกใช้แท็กจัดการข้อความที่ถูกต้องช่วยจัดโครงสร้างเนื้อหาให้อ่านง่าย และช่วยให้ระบบค้นหาเข้าใจลำดับความสำคัญของเนื้อหา

3.2.1.1 การใช้ Heading <h1> - <h6>

Heading ใช้กำหนดหัวข้อของเนื้อหา มี 6 ระดับ ตั้งแต่ <h1> ซึ่งสำคัญที่สุด ไปจนถึง <h6> ซึ่งสำคัญน้อยที่สุด โดยในหนึ่งหน้าเว็บควรมี <h1> เพียงตัวเดียว

แท็กระดับความสำคัญการใช้งาน
<h1>สำคัญที่สุดชื่อเรื่องหลัก หรือพาดหัวหลัก
<h2>สำคัญรองลงมาหัวข้อหลักของเนื้อหาย่อย
<h3> ถึง <h6>ลดหลั่นลงไปหัวข้อย่อยสำหรับรายละเอียดเพิ่มเติม

3.2.1.2 การจัดย่อหน้าด้วย <p> และการขึ้นบรรทัดใหม่ด้วย <br>

แท็ก <p> ใช้จัดกลุ่มข้อความให้เป็นย่อหน้า โดยเบราว์เซอร์จะเว้นระยะระหว่างย่อหน้าให้อัตโนมัติ ส่วน <br> ใช้บังคับให้ข้อความขึ้นบรรทัดใหม่ทันที

3.3 การสร้างรายการข้อมูล (Lists)

การสร้างรายการช่วยจัดข้อมูลให้เป็นหมวดหมู่และอ่านได้ง่าย โดย HTML5 แบ่งรายการหลักเป็น Unordered Lists, Ordered Lists และ Nested Lists

3.3.1 รายการแบบไม่มีลำดับ (Unordered Lists <ul>)

เหมาะกับข้อมูลที่ลำดับก่อนหลังไม่มีความสำคัญ เช่น รายการวัตถุดิบหรืออุปกรณ์ โดยใช้ <ul> ครอบรายการ และใช้ <li> สำหรับข้อมูลแต่ละข้อ

3.3.2 รายการแบบมีลำดับ (Ordered Lists <ol>)

เหมาะกับข้อมูลที่ลำดับมีความสำคัญ เช่น ขั้นตอนการสมัครสมาชิกหรือขั้นตอนการทำอาหาร โดยใช้ <ol> และ <li>

  • type กำหนดรูปแบบ เช่น A, a, I หรือ 1
  • start กำหนดจุดเริ่มต้นของการนับ เช่น start="5"
  • reversed ทำให้รายการนับถอยหลัง

3.3.3 รายการแบบซ้อนทับกัน (Nested Lists)

Nested Lists คือการนำรายการไปซ้อนไว้ภายในรายการอื่น โดยรายการย่อยต้องอยู่ภายในแท็ก <li> ของรายการหลักเสมอ เพื่อให้โครงสร้างถูกต้องและแสดงหมวดหมู่ได้ชัดเจน

3.4 การตั้งค่าและใช้งานส่วนขยาย (Extensions) เชิงลึก

Extension ใน Visual Studio Code ช่วยเพิ่มความสามารถในการเขียนเว็บไซต์ ทำให้นักพัฒนาทำงานได้เร็วขึ้น ลดขั้นตอนที่ทำซ้ำ และช่วยลดข้อผิดพลาด

3.4.1 วิธีการค้นหาและติดตั้งที่ถูกต้อง

สามารถเปิด Extensions ใน VS Code ได้จากไอคอนด้านซ้าย หรือใช้คีย์ลัด Ctrl+Shift+X ก่อนติดตั้งควรตรวจสอบ Verified Publisher และยอดดาวน์โหลด เพื่อช่วยลดความเสี่ยงจากส่วนขยายที่ไม่น่าเชื่อถือ

3.4.2 Code Formatting & Syntax

Prettier ใช้จัดรูปแบบและจัดย่อหน้าโค้ดให้เป็นระเบียบ ส่วน Error Lens ช่วยแสดงตำแหน่งข้อผิดพลาดและข้อความแจ้งเตือนในโค้ด

3.4.3 HTML Tag Automation

Auto Rename Tag ช่วยเปลี่ยนชื่อแท็กปิดให้ตรงกับแท็กเปิดโดยอัตโนมัติ และ Auto Close Tag ช่วยเติมแท็กปิดให้โดยอัตโนมัติหลังจากพิมพ์แท็กเปิด

3.4.4 ทำความเข้าใจ Live Server

Live Server ช่วยอัปเดตผลลัพธ์แบบ Realtime และจำลอง Local Server บนเครื่องคอมพิวเตอร์

การเปิดไฟล์ HTML โดยตรงจะใช้ File Protocol (file:///) แต่เมื่อใช้ Live Server จะใช้ HTTP Protocol เช่น http://127.0.0.1 หรือ localhost ทำให้สภาพแวดล้อมใกล้เคียงกับเว็บไซต์จริงมากกว่า

สรุป

HTML5 เป็นภาษาที่ใช้สร้างโครงสร้างเว็บไซต์ โดยมีโครงสร้างหลักคือ <!DOCTYPE html>, <html>, <head> และ <body> การใช้ Tag และ Attribute อย่างถูกต้องช่วยให้เว็บไซต์มีโครงสร้างที่ชัดเจน

Heading ใช้จัดลำดับหัวข้อ ส่วน <p> ใช้จัดย่อหน้า และ <br> ใช้ขึ้นบรรทัดใหม่ นอกจากนี้ยังสามารถสร้างรายการแบบ <ul>, <ol> และ Nested Lists เพื่อจัดข้อมูลให้เป็นหมวดหมู่

Extension เช่น Prettier, Error Lens, Auto Rename Tag และ Auto Close Tag ช่วยเพิ่มความสะดวกและลดข้อผิดพลาดในการเขียนโค้ด ส่วน Live Server ช่วยจำลอง Local Server และแสดงผลเว็บไซต์แบบ Realtime
