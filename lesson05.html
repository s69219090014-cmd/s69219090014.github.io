⬅ กลับไปหน้าหลัก

บทที่ 5 การจัดการข้อความและสื่อมัลติมีเดีย

5.1 การจัดการข้อความระดับสูง

หลังจากที่เราได้เรียนรู้วิธีการสร้างโครงสร้างเว็บไซต์ด้วย HTML และการจัดหน้าตาเลย์เอาต์ด้วย CSS ไปแล้วในบทก่อนหน้า ขั้นตอนต่อไปที่ถือเป็น "กระบอกเสียง" ของเว็บไซต์ก็คือข้อความหรือตัวอักษรนั่นเองครับ หากเปรียบเทียบการสร้างเว็บเป็นการสร้างร้านกาแฟ การจัดข้อความก็เปรียบเสมือนการออกแบบ "ป้ายเมนูและป้ายหน้าร้าน" หากป้ายเหล่านั้นใช้ตัวหนังสือที่เล็กเกินไป หรือใช้สีที่กลืนไปกับพื้นหลัง ลูกค้าก็คงไม่อยากเสียเวลาเพ่งอ่านและเดินออกจากร้านไปในที่สุด

การจัดการข้อความระดับสูงจึงไม่ใช่แค่การพิมพ์ข้อความลงไปในหน้าเว็บเฉยๆ แต่เป็นการผสมผสานศิลปะและเทคนิคการเขียนโค้ดเข้าด้วยกัน เพื่อดึงดูดสายตาผู้อ่าน สร้างลำดับความสำคัญของเนื้อหา และทำให้เว็บไซต์ของเราดูเป็นมืออาชีพมากยิ่งขึ้น ซึ่งเครื่องมือหลักที่เราจะใช้เนรมิตความสวยงามให้กับตัวอักษรก็คือภาษา CSS นั่นเองครับ

5.1.1 การปรับแต่งด้วย CSS

ภาษา CSS มีคุณสมบัติมากมายที่ถูกสร้างขึ้นมาเพื่อจัดการกับตัวอักษรโดยเฉพาะ ทำให้นักพัฒนาสามารถควบคุมรูปลักษณ์ของข้อความได้อย่างอิสระและแม่นยำในทุกๆ มิติ ตั้งแต่เรื่องพื้นฐานอย่างสีและขนาด ไปจนถึงการเปลี่ยนรูปแบบตัวอักษร (Font) ให้มีเอกลักษณ์เฉพาะตัว

5.1.1.1 การกำหนดสี (Color) และขนาด (Font-size)

คุณสมบัติพื้นฐานที่สุดในการตกแต่งข้อความคือการเปลี่ยนสี โดยในภาษา CSS เราจะใช้คำสั่ง color ในการเปลี่ยนสีของตัวอักษร การกำหนดสีนั้นไม่ได้ถูกจำกัดอยู่แค่การพิมพ์ชื่อสีภาษาอังกฤษธรรมดา (เช่น red, blue, green) เท่านั้น แต่นักพัฒนาสามารถใช้รหัสสีแบบ "Hex Code" (เช่น #FF5733) หรือรหัสสีแบบ "RGB" เพื่อผสมเฉดสีออกมาได้อย่างแม่นยำนับล้านเฉดสี เปรียบเสมือนการที่จิตรกรมีจานผสมสีส่วนตัวที่สามารถหยดสีแดง สีเขียว และสีน้ำเงิน ผสมกันจนได้เฉดสีที่ตรงกับเอกลักษณ์ของแบรนด์มากที่สุด

นอกจากสีแล้ว ขนาดของตัวอักษรก็มีความสำคัญไม่แพ้กัน โดยเราจะใช้คำสั่ง font-size ในการควบคุมความเล็กใหญ่ของข้อความ ในการกำหนดขนาดนั้นสามารถทำได้หลายหน่วย แต่หน่วยที่ผู้เริ่มต้นนิยมใช้และเข้าใจง่ายที่สุดคือหน่วย "พิกเซล (px)" ซึ่งเป็นการล็อกขนาดตัวอักษรแบบตายตัว การกำหนดขนาดตัวอักษรที่ดีควรคำนึงถึงหลักการจัดลำดับชั้นทางสายตา (Visual Hierarchy) โดยให้หัวข้อหลักมีขนาดใหญ่ที่สุด และเนื้อหาทั่วไปมีขนาดเล็กลงมาแต่อ่านได้สบายตา (มักจะไม่ต่ำกว่า 16px สำหรับการแสดงผลบนหน้าจอทั่วไป)

5.1.1.2 การใช้ Google Fonts

ในอดีต การเลือกใช้ฟอนต์บนหน้าเว็บไซต์มักมีข้อจำกัดอย่างมาก เพราะเว็บไซต์จะสามารถแสดงผลฟอนต์ได้ก็ต่อเมื่อ "เครื่องคอมพิวเตอร์ของผู้เข้าชมมีการติดตั้งฟอนต์นั้นไว้ในเครื่องด้วย" ทำให้นักพัฒนาต้องจำใจใช้ฟอนต์มาตรฐานที่ดูน่าเบื่ออย่าง Arial หรือ Times New Roman แต่ในปัจจุบัน ปัญหานี้ได้หมดไปเมื่อมีการถือกำเนิดขึ้นของระบบ Cloud Font Service ซึ่งบริการที่ได้รับความนิยมสูงสุดและเปิดให้ใช้งานฟรีก็คือ Google Fonts

Google Fonts เปรียบเสมือน "ห้องสมุดฟอนต์ระดับโลกที่ลอยอยู่บนคลาวด์" วิธีการทำงานของมันคือ แทนที่เราจะบังคับให้ผู้ใช้งานต้องดาวน์โหลดฟอนต์ไปติดตั้งในเครื่อง เราจะใช้แท็ก <link> แปะไว้ในส่วน <head> ของไฟล์ HTML เพื่อสั่งให้เบราว์เซอร์วิ่งไปขอยืมฟอนต์สวยๆ จากเซิร์ฟเวอร์ของ Google มาแสดงผลบนหน้าจอแบบเรียลไทม์ จากนั้นเราก็เพียงแค่ใช้คำสั่ง font-family ใน CSS เพื่อเรียกชื่อฟอนต์นั้นมาตกแต่งข้อความได้ทันที ทำให้เว็บไซต์ของเราดูทันสมัยและมีเอกลักษณ์ ไม่ว่าจะถูกเปิดจากคอมพิวเตอร์หรือสมาร์ตโฟนเครื่องใดก็ตาม

ตัวอย่างการปฏิบัติ: การเปลี่ยนสี ขนาด และเชื่อมต่อ Google Fonts ให้นักศึกษาเข้าไปที่เว็บไซต์ fonts.google.com แล้วเลือกฟอนต์ภาษาไทยที่ชื่อว่า 'Sarabun' (สารบรรณ) จากนั้นนำลิงก์มาแปะลงในโค้ด HTML และตกแต่งด้วย CSS ตามตัวอย่างด้านล่างนี้ครับ

5.2 การแทรกรูปภาพและสื่อ

แม้ว่าข้อความจะเป็นกระบอกเสียงหลักในการสื่อสารข้อมูล แต่เว็บไซต์ที่มีเพียงแค่ตัวหนังสือย่อมดูจืดชืดและไม่น่าดึงดูดใจ หากเปรียบเทียบเว็บไซต์เป็น "ร้านกาแฟ" ข้อความก็คือป้ายบอกชื่อเมนู แต่รูปภาพและสื่อมัลติมีเดียคือ "ตู้กระจกที่โชว์เมล็ดกาแฟและเค้กหน้าตาน่ารับประทาน" ซึ่งเป็นสิ่งสำคัญที่ช่วยกระตุ้นความสนใจ สร้างอารมณ์ร่วม และทำให้ผู้ใช้งานเข้าใจเนื้อหาได้รวดเร็วยิ่งขึ้นโดยไม่ต้องเสียเวลาอ่านข้อความยาวๆ

การแทรกสื่อต่างๆ ลงในเว็บไซต์นั้น HTML5 ได้เตรียมเครื่องมือไว้ให้อย่างครบครัน ไม่ว่าจะเป็นรูปภาพ วิดีโอ หรือเสียง แต่สิ่งสำคัญที่นักพัฒนาจะต้องคำนึงถึงไม่ได้มีเพียงแค่การนำรูปมาแปะให้แสดงผลได้เท่านั้น แต่ยังรวมไปถึงการจัดการขนาดไฟล์ และการอ้างอิงที่อยู่ไฟล์ให้ถูกต้อง เพื่อให้เว็บไซต์สามารถโหลดขึ้นมาแสดงผลได้อย่างรวดเร็วและไม่มีรูปภาพสูญหาย

5.2.1 การใช้แท็ก <img>

สำหรับการนำรูปภาพมาแสดงบนหน้าเว็บ เราจะใช้แท็กที่ชื่อว่า <img> (ย่อมาจาก Image) ซึ่งมีความพิเศษแตกต่างจากแท็กข้อความทั่วไปตรงที่ <img> เป็น "แท็กเดี่ยว" (Empty Tag) ที่ไม่ต้องมีแท็กปิด </img> มารองรับ หน้าที่ของมันไม่ใช่การนำรูปภาพมาฝังไว้ในไฟล์โค้ดโดยตรง แต่เป็นการ "ชี้เป้าหมาย" เพื่อสั่งให้เว็บเบราว์เซอร์วิ่งไปหยิบรูปภาพจากแหล่งเก็บข้อมูล แล้วนำมาฉายลงบนหน้าจอ

ในการชี้เป้าหมายนั้น แท็ก <img> จะต้องทำงานร่วมกับแอตทริบิวต์ที่ขาดไม่ได้เลยนั่นคือ src (ย่อมาจาก Source) ซึ่งทำหน้าที่ระบุที่อยู่ของไฟล์ภาพ หากนักพัฒนาพิมพ์แท็ก <img> ลอยๆ โดยไม่ใส่แอตทริบิวต์ src เบราว์เซอร์ก็จะไม่รู้ว่าต้องไปนำรูปภาพจากที่ไหนมาแสดงผล

5.2.1.1 การระบุที่อยู่ไฟล์ (Path) ทั้งแบบ Relative และ Absolute

การระบุที่อยู่ของไฟล์ภาพในแอตทริบิวต์ src นั้นสามารถทำได้ 2 รูปแบบหลัก ซึ่งนักพัฒนาจะต้องเลือกใช้ให้เหมาะสมกับสถานการณ์ เปรียบเสมือนการบอกทางให้เพื่อนเดินทางมาหาเรา

รูปแบบลักษณะข้อดี / ข้อเสีย
Absolute Path (เส้นทางสัมบูรณ์) เปรียบเสมือนการให้ "ที่อยู่ไปรษณีย์แบบเต็มรูปแบบ" (บ้านเลขที่ ถนน ตำบล จังหวัด ประเทศ) เริ่มต้นด้วย http:// หรือ https:// เสมอ เพื่อชี้ไปยังรูปภาพที่ถูกเก็บไว้ในเว็บไซต์อื่นบนอินเทอร์เน็ต ข้อดีคือง่ายและรวดเร็ว แต่ข้อเสียคือหากวันหนึ่งเว็บไซต์ต้นทางลบรูปภาพนั้นทิ้ง รูปภาพบนเว็บไซต์ของเราก็จะหายไปและกลายเป็นกรอบสี่เหลี่ยมแตกๆ ทันที
Relative Path (เส้นทางสัมพัทธ์) เปรียบเสมือนการ "บอกทางจากจุดที่เรายืนอยู่" (เดินออกจากห้องนี้ เลี้ยวซ้าย แล้วเปิดแฟ้มชื่อ Images) ใช้สำหรับดึงรูปภาพที่ดาวน์โหลดมาเก็บไว้ในโฟลเดอร์โปรเจกต์ของตัวเอง (Local Folder) เช่น src="images/coffee.jpg" คือมาตรฐานระดับมืออาชีพที่อุตสาหกรรมใช้กัน เพราะรูปภาพจะอยู่ติดตัวไปกับเว็บไซต์ของเราเสมอไม่ว่าจะย้ายระบบไปที่ใดก็ตาม

5.2.1.2 การจัดการความละเอียดและขนาดไฟล์เพื่อประสิทธิภาพของเว็บ

ปัญหาคลาสสิกของผู้เริ่มต้นทำเว็บไซต์คือ การนำรูปภาพความละเอียดสูงลิบลิ่ว (เช่น ภาพขนาด 10MB จากกล้องโปร) มาใส่ในหน้าเว็บไซต์โดยตรง ซึ่งการกระทำเช่นนี้ถือเป็นหายนะต่อประสิทธิภาพของเว็บ (Web Performance) อย่างมาก เพราะจะทำให้หน้าเว็บไซต์โหลดช้า กินอินเทอร์เน็ตของผู้ใช้งาน และส่งผลให้คะแนน SEO (Search Engine Optimization) ตกต่ำลงอย่างหลีกเลี่ยงไม่ได้

นักพัฒนามืออาชีพจะต้องทำการ "บีบอัดและย่อขนาดภาพ" (Image Optimization) ก่อนนำมาใช้งานเสมอ โดยควรย่อความกว้างของภาพให้เหมาะสมกับการแสดงผลบนหน้าจอ (เช่น ภาพประกอบบทความไม่ควรมีความกว้างเกิน 1200 พิกเซล) และควรเปลี่ยนสกุลไฟล์ให้เหมาะสมกับประเภทของงาน ดังนี้

.jpgใช้สำหรับภาพถ่ายทั่วไป
.pngใช้สำหรับภาพกราฟิกที่ต้องการพื้นหลังโปร่งใส
.webpไฟล์มาตรฐานใหม่ ขนาดเล็กจิ๋วแต่คมชัดเท่าเดิม

ตัวอย่างการปฏิบัติ: การแทรกรูปภาพและการใช้แอตทริบิวต์ที่สำคัญ ให้นักศึกษาสร้างโฟลเดอร์ชื่อ images ไว้ในโฟลเดอร์โปรเจกต์ นำรูปภาพเข้าไปเก็บไว้ 1 รูป และทำการทดลองพิมพ์โค้ดเพื่อแทรกรูปภาพลงบนหน้าเว็บไซต์ โดยสังเกตการทำงานของแอตทริบิวต์แต่ละตัวดังนี้

5.3 การจัดการวิดีโอและเสียง

ในยุคปัจจุบันที่อินเทอร์เน็ตมีความเร็วสูงขึ้น การนำเสนอข้อมูลไม่ได้จำกัดอยู่เพียงแค่ข้อความหรือรูปภาพนิ่งอีกต่อไป การเพิ่มวิดีโอและเสียงลงในเว็บไซต์เปรียบเสมือนการยกระดับจาก "ป้ายโฆษณาธรรมดา" ให้กลายเป็น "โรงภาพยนตร์ส่วนตัว" ที่สามารถดึงดูดความสนใจ ถ่ายทอดอารมณ์ และอธิบายเนื้อหาที่ซับซ้อนให้เข้าใจได้ง่ายขึ้นภายในเวลาไม่กี่นาที

ในอดีต การจะนำวิดีโอมาเล่นบนหน้าเว็บได้นั้น นักพัฒนาต้องพึ่งพาโปรแกรมเสริม (Plugin) จากภายนอก เช่น Flash Player ซึ่งมักจะมีปัญหาเรื่องความปลอดภัยและทำให้เครื่องคอมพิวเตอร์ทำงานช้า แต่ด้วยความสามารถของมาตรฐาน HTML5 ในปัจจุบัน เว็บเบราว์เซอร์สามารถอ่านและเล่นไฟล์สื่อมัลติมีเดียเหล่านี้ได้ด้วยตัวเองอย่างลื่นไหล ทำให้การเขียนโค้ดเพื่อแทรกวิดีโอและเสียงกลายเป็นเรื่องที่ง่าย ปลอดภัย และมีประสิทธิภาพสูงขึ้นมาก

5.3.1 แท็กสื่อมัลติมีเดีย ภาษา HTML5

HTML5 ได้เตรียมแท็กเฉพาะกิจสำหรับการจัดการสื่อมัลติมีเดียไว้ให้เราใช้งานอย่างเป็นระบบ โดยแยกย่อยออกเป็นแท็ก <video> สำหรับภาพเคลื่อนไหว และแท็ก <audio> สำหรับไฟล์เสียง ซึ่งแท็กทั้งสองประเภทนี้จะมีรูปแบบการใช้งานและแอตทริบิวต์ที่คล้ายคลึงกัน ทำให้ผู้เริ่มต้นสามารถทำความเข้าใจและนำไปประยุกต์ใช้ได้ง่าย

5.3.1.1 การแทรกวิดีโอด้วย <video> และการคุมปุ่ม (Controls)

การนำวิดีโอมาแสดงผลบนหน้าเว็บไซต์นั้น เราจะใช้แท็กคู่ที่ชื่อว่า <video> ... </video> โดยหลักการทำงานเบื้องต้นจะคล้ายกับการแทรกรูปภาพ คือจะต้องมีแอตทริบิวต์ src (Source) เพื่อระบุเส้นทางไปหาไฟล์วิดีโอ (เช่น ไฟล์นามสกุล .mp4) และควรมีการกำหนดขนาดด้วยแอตทริบิวต์ width เพื่อไม่ให้วิดีโอขยายสัดส่วนจนล้นหน้าจอ

อย่างไรก็ตาม หากเราเขียนโค้ดใส่แค่เส้นทางไฟล์วิดีโอเพียงอย่างเดียว วิดีโอจะปรากฏขึ้นมาเป็นเพียงภาพนิ่งๆ ที่ไม่สามารถกดเล่นได้ ดังนั้นแอตทริบิวต์ที่เป็น "หัวใจสำคัญ" ของการจัดการวิดีโอคือ controls เมื่อเราพิมพ์แอตทริบิวต์นี้เสริมเข้าไปในแท็กเปิด เบราว์เซอร์จะทำการเสก "แผงควบคุม" ขึ้นมาซ้อนทับบนวิดีโอให้ผู้ใช้งานโดยอัตโนมัติ ซึ่งจะประกอบไปด้วยปุ่มเล่น/หยุด (Play/Pause) แถบเวลา (Timeline) ปุ่มปรับระดับเสียง (Volume) และปุ่มขยายเต็มจอ (Fullscreen) เปรียบเสมือนการมอบรีโมททีวีให้กับผู้เยี่ยมชมเว็บไซต์นั่นเอง

ตัวอย่างการปฏิบัติ: การแทรกวิดีโอพร้อมแผงควบคุม ให้นักศึกษาลองสร้างโฟลเดอร์ชื่อ videos แล้วนำไฟล์วิดีโอ .mp4 เข้าไปเก็บไว้ 1 ไฟล์ จากนั้นให้พิมพ์โค้ดด้านล่างนี้เพื่อทดสอบการแสดงผลแผงควบคุมวิดีโอ

5.4 การสร้างเฟรมด้วย Inline Frame (Iframe)

ในอดีต การสร้างเว็บไซต์นิยมใช้เทคนิคการแบ่งหน้าจอออกเป็นหลายๆ เฟรม (Frameset) เพื่อแสดงผลหน้าเว็บหลายหน้าพร้อมกัน แต่ในยุคปัจจุบันของภาษา HTML5 เทคนิคแบบเก่าได้ถูกยกเลิกไปแล้ว เนื่องจากทำให้เสิร์ชเอนจิน (SEO) เก็บข้อมูลยากและไม่รองรับกับหน้าจอสมาร์ตโฟน อย่างไรก็ตาม ความต้องการในการ "ดึงเนื้อหาจากเว็บอื่นมาแสดง" ยังคงมีความจำเป็นอย่างมาก HTML5 จึงเปลี่ยนมาใช้เทคโนโลยีที่เรียกว่า Inline Frame หรือการใช้แท็ก <iframe> แทน

เปรียบเสมือนการที่เรา "เจาะหน้าต่างบานกระจก" ไว้บนกำแพงหน้าเว็บไซต์ของเรา เพื่อให้ผู้ใช้งานสามารถมองทะลุออกไปเห็นเนื้อหา หน้าเว็บ หรือแอปพลิเคชันจากเว็บไซต์อื่นๆ (Third-party) ได้ โดยที่ผู้ใช้ไม่ต้องกดปุ่มลิงก์ย้ายออกจากหน้าเว็บของเราเลย

5.4.1 หลักการทำงานและโครงสร้างแท็ก <iframe>

การทำงานของแท็ก <iframe> จะมีความคล้ายคลึงกับการแทรกรูปภาพหรือการแทรกวิดีโอ คือจะต้องมีการชี้ "เป้าหมาย (Source)" เสมอ แต่สิ่งที่จะถูกนำมาแสดงนั้นคือเว็บไซต์ทั้งหน้า โดยมีแอตทริบิวต์ที่สำคัญดังนี้:

  • src (Source): ระบุ URL หรือที่อยู่ของหน้าเว็บไซต์ภายนอกที่เราต้องการดึงมาแสดงผล (ต้องอ้างอิงที่อยู่ไฟล์แบบ Absolute Path ที่ขึ้นต้นด้วย https://)
  • width และ height: ใช้กำหนดความกว้างและความสูงของกรอบหน้าต่างเฟรม (มักใช้เป็นหน่วยพิกเซล px หรือเปอร์เซ็นต์ %)
  • title: เป็นข้อความอธิบายสั้นๆ ว่าเฟรมกระจกบานนี้กำลังแสดงอะไร ถือเป็นแอตทริบิวต์ที่บังคับให้ใส่ เพื่อให้ระบบโปรแกรมอ่านหน้าจอสำหรับผู้พิการทางสายตา (Screen Reader) สามารถเข้าใจเนื้อหาได้
  • allowfullscreen: เป็นแอตทริบิวต์พิเศษที่เมื่อใส่ลงไป จะอนุญาตให้ผู้ใช้กดขยายเนื้อหาในเฟรมนี้ให้เต็มหน้าจอได้ (นิยมใช้อย่างมากกับการฝังคลิปวิดีโอ)

5.4.2 การประยุกต์ใช้งานการฝังแผนที่ Google Maps หรือการดึงวิดีโอจาก YouTube

ในโลกของการพัฒนาเว็บไซต์ระดับมืออาชีพ เราแทบจะไม่ใช้ <iframe> ในการดึงหน้าเว็บไซต์ข่าวหรือเว็บความรู้ธรรมดาๆ มาแสดงแล้ว แต่เราจะนำมาประยุกต์ใช้ในลักษณะของการ "ฝัง (Embed) บริการระดับโลก" เข้ามาเป็นส่วนหนึ่งในเว็บของเรา ซึ่งมีประโยชน์มหาศาลคือ "เราไม่ต้องเปลืองพื้นที่เซิร์ฟเวอร์ของเราเอง" และลดภาระการเขียนโค้ดระบบที่ซับซ้อน ตัวอย่างที่ได้รับความนิยมสูงสุดได้แก่:

  1. การฝังวิดีโอจาก YouTube: แทนที่เราจะต้องบีบอัดไฟล์และอัปโหลดวิดีโอที่มีขนาดใหญ่ลิบลิ่วลงในเซิร์ฟเวอร์เว็บของตัวเอง (เหมือนในหัวข้อ 5.3) เราเพียงแค่นำไฟล์ไปอัปโหลดลง YouTube จากนั้นกดปุ่ม Share (แชร์) -> Embed (ฝัง) ระบบของ YouTube จะสร้างรหัสโค้ด <iframe> มาให้เราคัดลอกไปแปะในเว็บไซต์ได้ทันที แถมยังได้แผงควบคุมวิดีโอที่ทันสมัยและคุ้นตาของ YouTube มาใช้งานด้วย
  2. การฝังแผนที่ Google Maps: สำหรับหน้า "ติดต่อเรา" แทนที่เราจะจับภาพหน้าจอ (Screenshot) แผนที่ร้านค้ามาแปะเป็นภาพนิ่งๆ เราสามารถเข้าไปที่เว็บไซต์ Google Maps ค้นหาสถานที่ร้าน กด Share -> Embed a map แล้วนำโค้ด <iframe> มาวาง ลูกค้าก็จะสามารถใช้เมาส์เลื่อนดูแผนที่ ซูมเข้า-ซูมออก หรือกดปุ่มเปิดระบบนำทาง GPS บนเว็บไซต์ของเราได้แบบ Interactive ทันที

ตัวอย่างการปฏิบัติ: การฝังวิดีโอและแผนที่ด้วย Iframe ให้นักศึกษาลองคัดลอกโค้ดด้านล่างนี้ไปวางในส่วน <body> เพื่อดูผลลัพธ์ของการดึงเนื้อหาจากเซิร์ฟเวอร์ระดับโลกมาจัดแสดงไว้บนหน้าเว็บเพจของตนเอง

สรุปท้ายบท

เนื้อหาในบทนี้ได้เชื่อมโยงทฤษฎีการสื่อสารด้วยภาพเข้ากับการทำงานจริงของเว็บไซต์ผ่านกระบวนการจัดการข้อความและสื่อมัลติมีเดีย (Text & Multimedia Management) การตกแต่งข้อความด้วยคำสั่ง CSS เช่น color และ font-size นั้น ทำให้เว็บไซต์สามารถดึงดูดสายตาและสร้างลำดับความสำคัญของเนื้อหาได้อย่างชัดเจน โดยต้องอาศัยเครื่องมือระดับสากลอย่างบริการคลาวด์ Google Fonts เป็นตัวเชื่อมโยงเพื่อดึงรูปแบบตัวอักษรที่สวยงามมาประยุกต์ใช้บนหน้าเว็บอย่างถูกต้อง พร้อมทั้งใช้การอ้างอิงผ่านแท็ก <link> เพื่อสร้างเอกลักษณ์ให้กับแบรนด์โดยไม่ต้องพึ่งพาข้อจำกัดเรื่องฟอนต์ในเครื่องคอมพิวเตอร์ของผู้ใช้งาน

ในขณะเดียวกัน การทำความเข้าใจระบบการอ้างอิงไฟล์สื่อ ถือเป็นกุญแจสำคัญที่สุดในการนำเสนอภาพลักษณ์ของเว็บไซต์ หลักการที่สำคัญที่สุดในกระบวนการนี้คือการแทรกรูปภาพผ่านแท็กเดี่ยว <img> คู่กับแอตทริบิวต์ src โดยต้องแยกแยะการระบุที่อยู่ไฟล์แบบ Absolute Path และ Relative Path ให้ถูกต้อง รวมถึงต้องทำการบีบอัดขนาดภาพ (Image Optimization) อยู่เสมอ ซึ่งเปรียบเสมือนการจัดเตรียมตู้โชว์ขนมหน้าร้านที่สวยงามและไม่กินพื้นที่ทางเดินจนเกินไป หากละเลยหลักการข้อนี้ เว็บเบราว์เซอร์จะไม่สามารถทำงานได้อย่างมีประสิทธิภาพ และจะเกิดข้อผิดพลาดร้ายแรงที่ทำให้หน้าเว็บไซต์โหลดช้า กินอินเทอร์เน็ต และส่งผลให้คะแนน SEO ตกต่ำลงอย่างหลีกเลี่ยงไม่ได้

ท้ายที่สุด การนำความเข้าใจเรื่องการจัดการไฟล์ภาพมาประกอบกับคำสั่งแทรกสื่อขั้นสูงอย่างแท็ก <video> พร้อมแอตทริบิวต์ controls และเทคนิคการเจาะหน้าต่างเชื่อมโลกด้วย <iframe> ทำให้เกิดเป็นรูปแบบการนำเสนอเนื้อหาที่สมบูรณ์และโต้ตอบได้ ผู้พัฒนาโปรแกรมได้เรียนรู้วิธีการออกแบบหน้าเว็บไซต์ที่ดูเป็นมืออาชีพและประหยัดพื้นที่เซิร์ฟเวอร์ การฝึกฝนเขียนโค้ดสื่อมัลติมีเดียบูรณาการ เช่น การฝังคลิปวิดีโอจาก YouTube หรือการแสดงแผนที่นำทางแบบ Interactive จาก Google Maps จะช่วยพัฒนากระบวนการคิดในการบริหารจัดการทรัพยากรเว็บไซต์ให้เป็นระบบ ซึ่งเป็นพื้นฐานที่แข็งแกร่งก่อนจะก้าวเข้าสู่การนำ "การสร้างตารางข้อมูล (Tables)" มาจัดระเบียบข้อมูลที่มีความซับซ้อนให้เป็นหมวดหมู่ในบทเรียนถัดไป
