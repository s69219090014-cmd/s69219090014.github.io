⬅ กลับไปหน้าหลัก

บทที่ 7 ระบบการเชื่อมโยง (Hyperlinks)

7.1 พื้นฐานการทำลิงก์

ลองจินตนาการถึงโลกที่ไม่มีสะพาน ไม่มีถนน หรือไม่มีเครื่องบิน เมืองแต่ละเมืองก็คงจะถูกตัดขาดออกจากกันอย่างสิ้นเชิง กลายเป็นเกาะแก่งที่โดดเดี่ยว เว็บไซต์ก็เช่นเดียวกันครับ หากเราสร้างหน้าเว็บเพจขึ้นมาหลายๆ หน้า แต่ไม่มีการเชื่อมต่อถึงกัน ผู้ใช้งานก็จะไม่สามารถเดินทางไปอ่านเนื้อหาในหน้าอื่นๆ ได้เลย

ด้วยเหตุนี้ "ระบบการเชื่อมโยง" หรือ ไฮเปอร์ลิงก์ (Hyperlinks) จึงถูกคิดค้นขึ้นมาเพื่อเป็น "สะพานหรือประตูวิเศษ" ที่ช่วยให้ผู้ใช้งานสามารถคลิกข้อความหรือรูปภาพ แล้ววาร์ปข้ามไปยังหน้าเพจอื่นๆ หรือแม้แต่ข้ามไปยังเว็บไซต์ของคนอื่นที่อยู่อีกซีกโลกหนึ่งได้ในพริบตา ซึ่งระบบการเชื่อมโยงข้อมูลโยงใยไปมาเป็นตาข่ายนี้เอง คือหัวใจสำคัญและเป็นจุดกำเนิดของคำว่า "World Wide Web (เครือข่ายใยแมงมุมระดับโลก)" อย่างแท้จริง

7.1.1 การใช้แท็ก <a> ในภาษา HTML

เครื่องมือหลักที่เราจะใช้ในการสร้างประตูมิติหรือลิงก์เชื่อมโยง คือแท็กคู่ที่ชื่อว่า <a> ซึ่งย่อมาจากคำว่า "Anchor" (สมอเรือ) แต่การพิมพ์เพียงแค่แท็ก <a>คลิกที่นี่</a> นั้นยังไม่เพียงพอที่จะทำให้เกิดการเชื่อมโยงได้ เพราะเบราว์เซอร์จะไม่รู้ว่าเมื่อผู้ใช้คลิกแล้ว จะต้องพาผู้ใช้เดินทางไปที่ไหน เปรียบเสมือนการสร้างประตูปลอมๆ ทิ้งไว้บนกำแพงโดยไม่มีปลายทาง

เพื่อให้ประตูบานนี้ทำงานได้จริง เราจะต้องใส่แอตทริบิวต์ที่เป็นหัวใจสำคัญชื่อว่า href (ย่อมาจาก Hypertext Reference) เข้าไปในแท็กเปิดเสมอ แอตทริบิวต์ href จะทำหน้าที่เป็น "ป้ายบอกทาง" เพื่อระบุที่อยู่ปลายทางที่แน่ชัดให้กับเบราว์เซอร์ ซึ่งเราสามารถแบ่งรูปแบบการกำหนดเป้าหมายการเดินทางออกเป็น 2 ประเภทหลักๆ ดังนี้

7.1.1.1 การเชื่อมโยงไปยังหน้าเพจภายในเว็บไซต์

เมื่อเราสร้างเว็บไซต์หนึ่งเว็บ เรามักจะมีไฟล์ HTML หลายไฟล์เก็บไว้ในโฟลเดอร์เดียวกัน (เช่น มีหน้า index.html เป็นหน้าแรก และมีหน้า about.html เป็นหน้าเกี่ยวกับเรา) การสร้างลิงก์เพื่อเดินทางไปมาระหว่างไฟล์เหล่านี้ เปรียบเสมือน "การเดินทะลุประตูจากห้องรับแขกไปยังห้องครัวภายในบ้านหลังเดียวกัน"

ในการเชื่อมโยงแบบภายในนี้ เราจะใช้การอ้างอิงที่อยู่ไฟล์แบบ Relative Path (เส้นทางสัมพัทธ์) โดยเราสามารถพิมพ์ชื่อไฟล์เป้าหมายลงไปใน href ได้โดยตรง เช่น <a href="about.html"> วิธีนี้คือเทคนิคมาตรฐานที่นักพัฒนาใช้ในการสร้าง "แถบเมนูนำทาง (Navigation Bar)" บนเว็บไซต์ เพื่อให้ผู้ใช้งานคลิกเปลี่ยนหน้าไปมาได้อย่างอิสระ

7.1.1.2 การเชื่อมโยงไปยังเว็บไซต์ภายนอก (External Link)

ในหลายๆ ครั้ง เราอาจต้องการอ้างอิงแหล่งข้อมูล หรือพาลูกค้าไปยังเว็บไซต์อื่นๆ ที่ไม่ได้อยู่ในเครื่องคอมพิวเตอร์ของเรา เช่น การทำปุ่มให้คลิกไปยัง Facebook ของร้านค้า หรือคลิกไปอ่านบทความใน Wikipedia การเชื่อมโยงลักษณะนี้เปรียบเสมือน "การนั่งเครื่องบินเดินทางข้ามประเทศไปยังบ้านของคนอื่น"

สำหรับการเชื่อมโยงแบบภายนอก เราจำเป็นจะต้องใช้ที่อยู่แบบ Absolute Path (เส้นทางสัมบูรณ์) ซึ่งก็คือการใส่ URL แบบเต็มรูปแบบที่ต้องขึ้นต้นด้วย http:// หรือ https:// เสมอ ตัวอย่างเช่น <a href="https://www.facebook.com"> หากเราลืมใส่ https:// เบราว์เซอร์จะเกิดความสับสนและคิดว่าเรากำลังพยายามหาไฟล์ที่ชื่อว่า facebook.com ซึ่งซ่อนอยู่ภายในโฟลเดอร์คอมพิวเตอร์ของเราเอง ทำให้ลิงก์นั้นพังและใช้งานไม่ได้

รูปที่ 7.1 เปรียบเทียบการทำงานของแท็ก Anchor ระหว่างการเชื่อมโยงภายในและการเชื่อมโยงภายนอก

📝 ตัวอย่างการปฏิบัติ: การสร้างลิงก์เชื่อมโยงภายในและภายนอก ให้นักศึกษาทดลองสร้างหน้าเว็บเพจ และพิมพ์โค้ดด้านล่างนี้เพื่อทดสอบการทำงานของแท็ก <a> ทั้ง 2 รูปแบบ โดยสังเกตความแตกต่างของการระบุข้อมูลในแอตทริบิวต์ href 
<!DOCTYPE html>
<html>
<head>
  <title>ทดสอบการทำลิงก์</title>
</head>
<body>

  <h1>เว็บไซต์ร้านกาแฟของเรา</h1>

  <!-- รูปแบบที่ 1: การเชื่อมโยงภายในเว็บไซต์ (Internal Link) -->
  <!-- พิมพ์แค่ชื่อไฟล์เป้าหมาย เพราะไฟล์อยู่ในโฟลเดอร์เดียวกัน -->
  <p>
    อ่านประวัติความเป็นมาของร้านเราได้ที่:
    <a href="about.html">เกี่ยวกับร้านกาแฟ</a>
  </p>

  <hr>

  <!-- รูปแบบที่ 2: การเชื่อมโยงไปยังเว็บไซต์ภายนอก (External Link) -->
  <!-- ต้องพิมพ์ URL เต็มรูปแบบพร้อม https:// เสมอ -->
  <p>
    ติดตามโปรโมชั่นใหม่ๆ ได้ที่แฟนเพจของเรา:
    <a href="https://www.facebook.com">Facebook ร้านกาแฟ</a>
  </p>

</body>
</html>

7.2 เทคนิคการเชื่อมโยง

หลังจากที่เราเข้าใจวิธีการสร้างลิงก์พื้นฐานเพื่อเดินทางข้ามไปมาระหว่างหน้าเว็บแล้ว ในการออกแบบเว็บไซต์ระดับมืออาชีพนั้น นักพัฒนาจำเป็นต้องควบคุม "พฤติกรรมของการคลิก" ให้เหมาะสมกับสถานการณ์ด้วย ลองจินตนาการว่า หากหน้าเว็บไซต์ของเรามีเนื้อหาที่ยาวมากๆ การปล่อยให้ผู้ใช้เลื่อนเมาส์ค้นหาข้อมูลเองย่อมสร้างความหงุดหงิด หรือในกรณีที่เราแนะนำให้ผู้ใช้คลิกไปดูข้อมูลที่เว็บไซต์อื่น แต่พอคลิกแล้วเว็บไซต์ของเรากลับถูกปิดหายไป ผู้ใช้ก็อาจจะลืมและไม่กลับมาที่เว็บไซต์ของเราอีกเลย

เพื่อแก้ปัญหาเหล่านี้ ภาษา HTML จึงได้เตรียมเทคนิคขั้นสูงในการควบคุมพฤติกรรมของลิงก์ไว้ให้เราใช้งาน ซึ่งจะช่วยยกระดับประสบการณ์ผู้ใช้งาน (UX) ให้มีความลื่นไหล สะดวกสบาย และทำให้เว็บไซต์ของเราดูเป็นมืออาชีพมากยิ่งขึ้น

7.2.1 การกำหนดเป้าหมาย (Target)

โดยธรรมชาติแล้ว เมื่อผู้ใช้งานคลิกที่แท็ก <a> เบราว์เซอร์จะทำการโหลดหน้าเว็บใหม่ขึ้นมา "ทับ" หน้าเว็บเดิมเสมอ (พฤติกรรมนี้เรียกว่า Self) แต่ในหลายๆ กรณี เราต้องการบอกเบราว์เซอร์ให้เปิดหน้าเว็บเป้าหมายในลักษณะที่แตกต่างออกไป เราสามารถทำได้โดยการเพิ่มแอตทริบิวต์ที่ชื่อว่า target ลงไปในแท็กเปิด <a> เพื่อทำหน้าที่เป็นตัวกำหนดเป้าหมายหรือพฤติกรรมการแสดงผลของหน้าต่างเบราว์เซอร์

7.2.1.1 การใช้ target="_blank" เพื่อเปิดแท็บใหม่

เมื่อเราต้องสร้างลิงก์เพื่อพาผู้ใช้งานไปยัง "เว็บไซต์ภายนอก" (External Link) กฎเหล็กของนักพัฒนาคือ เราไม่ควรให้เว็บภายนอกนั้นมาเปิดทับหน้าเว็บของเรา เปรียบเสมือนเวลาที่เราเปิดร้านขายของ แล้วเราอยากแนะนำให้ลูกค้าเดินไปดูสินค้าอีกร้านหนึ่ง เราก็คงไม่อยากผลักลูกค้าออกจากร้านเราแล้วล็อกประตูปิดตาย แต่เราอยากให้ลูกค้าเปิดประตูบานใหม่ไปดูโดยที่ตัวเขายังคงยืนอยู่ในร้านของเราด้วย

ในการเขียนโค้ด เราจะแก้ปัญหานี้โดยการใส่แอตทริบิวต์ target="_blank" เข้าไปในแท็ก <a> ทันทีที่ผู้ใช้งานคลิกลิงก์นี้ เบราว์เซอร์จะทำการ "เปิดแท็บใหม่ (New Tab)" ขึ้นมาด้านบนสุดเพื่อแสดงผลเว็บไซต์ปลายทาง โดยที่หน้าเว็บไซต์ของเราจะยังคงถูกเปิดค้างไว้ที่แท็บเดิมอย่างปลอดภัย ทำให้ผู้ใช้งานสามารถสลับแท็บกลับมาอ่านเนื้อหาในเว็บของเราต่อได้ตลอดเวลา

7.2.1.2 การทำ Anchor Link (ลิงก์ภายในหน้าเดิม)

ในกรณีที่หน้าเว็บไซต์ของเราเป็นบทความขนาดยาว หรือเป็นเว็บไซต์แบบหน้าเดียว (Single Page) การปล่อยให้ผู้ใช้เลื่อนหน้าจอ (Scroll) ลงไปลึกๆ เพื่อหาข้อมูลอาจทำให้ล้าและน่าเบื่อ เทคนิคการทำ Anchor Link จึงเปรียบเสมือนการสร้าง "ลิฟต์โดยสาร" ที่ช่วยให้ผู้ใช้งานคลิกที่สารบัญด้านบน แล้วจอภาพจะวาร์ปพุ่งตรงลงไปยังหัวข้อที่อยู่ด้านล่างสุดได้ทันทีโดยไม่ต้องออกแรงเลื่อนหน้าจอเอง

การสร้างลิฟต์โดยสารนี้ต้องทำงานร่วมกันเป็นคู่ ขั้นตอนแรกคือการ "สร้างจุดหมายปลายทาง" โดยเราจะไปที่แท็กหัวข้อด้านล่าง (เช่น <h2>) แล้วใส่แอตทริบิวต์ id พร้อมตั้งชื่อให้มัน (เช่น id="section2") ขั้นตอนที่สองคือการ "สร้างปุ่มกดลิฟต์" โดยเราจะสร้างแท็กลิงก์ <a> ไว้ด้านบนสุด และในช่อง href เราจะใส่เครื่องหมายแฮชแท็ก # ตามด้วยชื่อ id ปลายทางนั้น (เช่น href="#section2") เพียงเท่านี้ระบบลิฟต์ภายในหน้าเว็บของเราก็พร้อมใช้งานทันที

รูปที่ 7.2 เปรียบเทียบพฤติกรรมการเปิดแท็บใหม่และการกระโดดข้ามเนื้อหาด้วย Anchor Link

📝 ตัวอย่างการปฏิบัติ: การใช้งาน target="_blank" และ Anchor Link ให้นักศึกษาลองพิมพ์โค้ดด้านล่างนี้ และทดลองคลิกที่ลิงก์ทั้ง 2 ตัว เพื่อสังเกตพฤติกรรมของเบราว์เซอร์ที่แตกต่างกันอย่างชัดเจน 
<!DOCTYPE html>
<html>
<head>
  <title>เทคนิคการทำลิงก์</title>
</head>
<body>

  <!-- ส่วนที่ 1: การใช้ลิงก์เพื่อเปิดแท็บใหม่ -->
  <h1>เมนูหลัก</h1>
  <p>
    ติดตามข่าวสารของเราได้ที่เพจเฟซบุ๊ก
    <!-- ใส่ target="_blank" เพื่อสั่งบังคับเบราว์เซอร์เปิดแท็บใหม่ -->
    <a href="https://www.facebook.com" target="_blank">คลิกที่นี่เพื่อไป Facebook</a>
  </p>

  <hr>

  <!-- ส่วนที่ 2: การทำ Anchor Link (ลิฟต์วาร์ปในหน้าเดียวกัน) -->
  <!-- ปุ่มกดลิฟต์: ใส่ # ตามด้วยชื่อ id เป้าหมาย -->
  <p>
    อยากเลื่อนจอไปไหน?
    <a href="#bottom-section">คลิกตรงนี้เพื่อลงไปล่างสุดของเว็บทันที</a>
  </p>

  <!-- สร้างพื้นที่ว่างเยอะๆ เพื่อต้นเนื้อหาให้ตกอยู่ด้านล่างสุดของจอ -->
  <div style="height: 1500px; background-color: #f0f0f0;">
    (พื้นที่ว่างจำลองความยาวของหน้าเว็บ)
  </div>

  <!-- จุดหมายปลายทางของลิฟต์: ต้องใส่ id ให้ตรงกับปุ่มกดเรียบร้อย -->
  <h2 id="bottom-section">ยินดีด้วย! คุณวาร์ปมาถึงด้านล่างสุดแล้ว</h2>
  <p>นี่คือเนื้อหาที่อยู่ล่างสุดของเว็บไซต์</p>

</body>
</html>

7.3 การปรับแต่งลิงก์ด้วย CSS

หากลองสร้างลิงก์ด้วยแท็ก <a> เปล่าๆ โดยไม่มีการตกแต่งใดๆ จะพบว่าเว็บเบราว์เซอร์มีค่าเริ่มต้นในการแสดงผลลิงก์เป็น "ตัวอักษรสีน้ำเงินและมีเส้นใต้" เสมอ แม้ว่ารูปแบบนี้จะใช้งานได้จริงและสื่อความหมายชัดเจน แต่มันมักจะขัดแย้งกับความสวยงามและธีมสี (Color Palette) ของเว็บไซต์ในยุคปัจจุบัน เปรียบเสมือนการนำป้ายบอกทางจราจรสีน้ำเงินธรรมดาๆ ไปตั้งไว้กลางล็อบบี้โรงแรมหรูระดับห้าดาว ซึ่งดูไม่เข้ากันอย่างยิ่ง

ด้วยเหตุนี้ ภาษา CSS จึงเข้ามามีบทบาทสำคัญในการแปลงโฉมลิงก์ข้อความธรรมดา ให้กลายเป็นองค์ประกอบที่สวยงามและกลมกลืนกับเว็บไซต์ ไม่ว่าจะเป็นการเปลี่ยนสี ลบเส้นใต้ หรือแม้กระทั่งการเสกข้อความธรรมดาให้กลายเป็น "ปุ่มกด (Button)" ที่ดูทันสมัยและน่าคลิกมากยิ่งขึ้น

7.3.1 สถานะของลิงก์ (Link States)

ความพิเศษของลิงก์ที่แตกต่างจากข้อความทั่วไปคือ ลิงก์ไม่ได้เป็นแค่วัตถุที่อยู่นิ่งๆ แต่มันมี "วงจรชีวิตหรือสถานะ" ที่เปลี่ยนแปลงไปตามการกระทำของผู้ใช้งาน เปรียบเสมือนประตูเซนเซอร์อัตโนมัติ ที่ปกติจะปิดอยู่ แต่เมื่อเราเดินเข้าไปใกล้ประตูจะสว่างขึ้น และเมื่อเราออกแรงผลักประตูก็จะเปิดออก

ในการใช้ CSS เพื่อตกแต่งลิงก์นั้น เราจะต้องใช้เครื่องมือที่เรียกว่า Pseudo-class (คลาสเทียม) เข้ามาช่วยจับตาดูพฤติกรรมของผู้ใช้ เพื่อสั่งให้ลิงก์เปลี่ยนสีหรือเปลี่ยนรูปร่างไปตามสถานะต่างๆ ซึ่งการสร้างการตอบสนองเชิงโต้ตอบ (Interactive) นี้ ถือเป็นหัวใจสำคัญของการสร้างประสบการณ์ผู้ใช้งาน (UX) ที่ดีเยี่ยม

7.3.1.1 การกำหนดสีลิงก์ (Link, Visited, Hover, Active)

สถานะของลิงก์ในภาษา CSS ถูกแบ่งออกเป็น 4 จังหวะการทำงานหลักๆ ซึ่งนักพัฒนาสามารถกำหนดคำสั่งแยกจากกันได้อย่างอิสระ ดังต่อไปนี้

สถานะความหมาย
:link ลิงก์ปกติที่ยังไม่เคยคลิก เปรียบเสมือนเส้นทางใหม่ที่ผู้ใช้ยังไม่เคยเดินทางไปสำรวจ
:visited ลิงก์ที่ผู้ใช้เคยคลิกและเดินทางไปแล้ว เบราว์เซอร์จะจดจำและเปลี่ยนสี (ปกติเป็นสีม่วง)
:hover สถานะขณะที่นำเมาส์ไปวางพาดอยู่บนลิงก์ (ยังไม่ได้คลิก)
:active สถานะขณะที่กำลังออกแรงกดเมาส์ค้างไว้ลงบนลิงก์ 
<!DOCTYPE html>
<html>
<head>
<style>
  /* 1. สั่งลบเส้นใต้ของลิงก์ทั้งหมดทั้งไป และเปลี่ยนฟอนต์ */
  a {
    text-decoration: none;
    font-family: sans-serif;
    font-size: 18px;
  }

  /* 2. สถานะ :link และ :visited (กำหนดให้หน้าตาเหมือนกันเพื่อง่ายต่อการมองเห็น) */
  a:link, a:visited {
    background-color: #007BFF; /* พื้นหลังสีน้ำเงิน */
    color: white; /* ตัวอักษรสีขาว */
    padding: 10px 20px; /* เพิ่มพื้นที่ด้านในให้ดูเป็นกรอบปุ่ม */
    border-radius: 5px; /* ลบเหลี่ยมให้มุมปุ่มมีความโค้งมน */
    display: inline-block; /* สั่งให้ลิงก์กลายร่างเป็นกล่องเพื่อรับค่า Padding ได้สมบูรณ์ */
  }

  /* 3. สถานะ :hover (เมื่อนำเมาส์ไปชี้) */
  a:hover {
    background-color: #0056b3; /* เปลี่ยนสีพื้นหลังให้เป็นสีน้ำเงินเข้มขึ้น */
  }

  /* 4. สถานะ :active (ขณะกำลังออกแรงกดเมาส์) */
  a:active {
    background-color: #004085; /* เปลี่ยนเป็นสีน้ำเงินเข้มจัด */
  }
</style>
</head>
<body>

  <h2>ทดสอบการแต่งลิงก์ด้วย CSS</h2>
  <!-- สร้างลิงก์ที่เมื่อคลิกจะหน้าจอจะหน้าตาเหมือนปุ่มกด -->
  <a href="https://www.google.com" target="_blank">คลิกเพื่อค้นหาข้อมูล</a>

</body>
</html>

สรุปท้ายบท

เนื้อหาในบทนี้ได้เชื่อมโยงทฤษฎีการสื่อสารบนเครือข่ายเข้ากับการทำงานจริงของเว็บไซต์ผ่านกระบวนการสร้างระบบการเชื่อมโยง (Hyperlinks) การสร้างจุดเชื่อมโยงด้วยแท็ก <a> นั้น ทำให้เว็บไซต์สามารถทำงานเป็นโครงข่ายและพังทลายข้อจำกัดเรื่องพื้นที่ได้อย่างสมบูรณ์ โดยต้องอาศัยแอตทริบิวต์ที่เป็นหัวใจสำคัญอย่าง href เป็นตัวเชื่อมโยงเพื่อระบุเป้าหมายการเดินทางอย่างแม่นยำ พร้อมทั้งต้องแยกแยะรูปแบบการอ้างอิงที่อยู่ไฟล์ทั้งแบบสัมพัทธ์ (Relative Path) สำหรับการเชื่อมโยงภายใน และแบบสัมบูรณ์ (Absolute Path) สำหรับเว็บไซต์ภายนอก เพื่อสร้าง "ประตูวิเศษ" ที่พาผู้ใช้ไปยังปลายทางได้อย่างถูกต้อง

ในขณะเดียวกัน การควบคุมพฤติกรรมการคลิกถือเป็นกุญแจสำคัญที่สุดในการรักษาประสบการณ์ผู้ใช้งาน (UX) ที่ลื่นไหล หลักการที่สำคัญที่สุดในกระบวนการนี้คือการจัดการเป้าหมายการแสดงผลผ่านแอตทริบิวต์ target="_blank" สำหรับการเชื่อมโยงภายนอก และการใช้เทคนิค Anchor Link สำหรับเลื่อนเนื้อหาภายในหน้าเพจ ซึ่งเปรียบเสมือนการเปิดประตูบานใหม่ให้ลูกค้าโดยไม่ล็อกประตูปิดตายร้านเดิม และการสร้างลิฟต์โดยสารเพื่อวาร์ปข้ามเนื้อหาที่ยาวเหยียด หากละเลยหลักการข้อนี้ เว็บเบราว์เซอร์จะทำงานในรูปแบบดั้งเดิมที่นำหน้าเว็บใหม่มาโหลดทับหน้าเว็บเดิมเสมอ และจะเกิดปัญหาที่ทำให้ผู้ใช้งานสับสน หลงทาง หรือออกจากการใช้งานเว็บไซต์ของเราไปอย่างถาวร

ท้ายที่สุด การนำโครงสร้างไฮเปอร์ลิงก์มาประกอบกับการตกแต่งด้วยคำสั่ง CSS ผ่านคลาสเทียม (Pseudo-class) เพื่อจัดการวงจรชีวิตและสถานะของลิงก์ เช่น :hover และ :active ทำให้เกิดเป็นรูปแบบการนำเสนอที่โต้ตอบได้และสมบูรณ์ ผู้พัฒนาโปรแกรมได้เรียนรู้วิธีการออกแบบการเชื่อมโยงที่กลมกลืนกับหน้าเว็บไซต์ การฝึกฝนเขียนโค้ดปรับแต่งลิงก์บูรณาการ เช่น การลบเส้นใต้ข้อความ หรือการแปลงร่างข้อความธรรมดาให้กลายเป็น "ปุ่มกด (Button)" ที่มีลูกเล่นโต้ตอบ จะช่วยพัฒนากระบวนการคิดในการออกแบบปฏิสัมพันธ์กับผู้ใช้ให้เป็นระบบ ซึ่งเป็นพื้นฐานที่แข็งแกร่งก่อนจะก้าวเข้าสู่การนำ "แบบฟอร์ม (Forms)" มาใช้เป็นเครื่องมือรับข้อมูลจากผู้ใช้งานอย่างเต็มรูปแบบในบทเรียนถัดไป
