บทที่ 6 การสร้างตารางข้อมูล (Tables)

6.1 โครงสร้างตาราง (Table Structure)

การนำเสนอข้อมูลในรูปแบบตารางกริด (Grid) ช่วยให้ผู้ใช้งานอ่านและทำความเข้าใจได้ง่าย การสร้างตาราง HTML ต้องใช้แท็กหลายตัวทำงานร่วมกัน เปรียบเสมือนการสร้าง "ชั้นวางหนังสือ" ที่ต้องมีทั้งโครงตู้ ชั้นวางแต่ละชั้น และกล่องเก็บของที่วางอยู่บนชั้นนั้นๆ

6.1.1 การประกาศแท็กตาราง

ก่อนอื่นเราต้องกำหนดขอบเขตของตารางทั้งหมดด้วยแท็กคู่ <table> ... </table> เปรียบเสมือนโครงตู้หรือกรอบชั้นวางหนังสือ ข้อมูลทุกอย่างที่จะปรากฏในตารางจะต้องอยู่ภายในคู่แท็กนี้เสมอ

<table>
  <!-- ข้อมูลตารางจะอยู่ที่นี่ -->
</table>

6.1.1.1 การสร้างแถวด้วย <tr>

เมื่อมีโครงตู้แล้ว ขั้นตอนถัดไปคือการสร้าง "ชั้นวาง" แต่ละชั้นในแนวนอน โดยใช้แท็ก <tr> (ย่อมาจาก Table Row) ซ้อนเข้าไปด้านในแท็ก <table> ยิ่งมีแท็ก <tr> มากเท่าไหร่ ตารางก็จะยิ่งมีจำนวนแถวมากขึ้นเท่านั้น

<table>
  <tr> ... </tr>
  <tr> ... </tr>
  <tr> ... </tr>
</table>

6.1.1.2 การสร้างข้อมูลด้วย <td>

เมื่อมีชั้นวางแล้ว ลำดับต่อมาคือการนำ "กล่องข้อมูล" ไปจัดเรียงบนชั้นนั้นๆ โดยใช้แท็ก <td> (ย่อมาจาก Table Data) ซ้อนเข้าไปในแท็ก <tr> อีกทีหนึ่ง ยิ่งเพิ่มแท็ก <td> เข้าไปในแถวเดียวกันมากเท่าไหร่ ก็จะยิ่งสร้างการแบ่งคอลัมน์ (Column) ในแนวนอนมากขึ้นเท่านั้น

<tr>
  <td>ข้อมูล 1</td>
  <td>ข้อมูล 2</td>
</tr>

6.1.1.3 การสร้างส่วนหัวตารางด้วย <th>

สำหรับแถวบนสุดที่ทำหน้าที่เป็นหัวข้อของแต่ละคอลัมน์ เราจะใช้แท็ก <th> (ย่อมาจาก Table Heading) แทนที่จะใช้ <td> ธรรมดา ซึ่งจะมีคุณสมบัติพิเศษที่แตกต่างออกไปดังนี้:

  • ข้อความภายในจะแสดงผลเป็น ตัวหนา และ จัดกึ่งกลาง โดยอัตโนมัติ ไม่ต้องเขียนคำสั่ง CSS เพิ่มเติม
  • รองรับการทำงานร่วมกับโปรแกรมอ่านหน้าจอ (Screen Reader) สำหรับผู้พิการทางสายตา ทำให้ระบบเข้าใจได้ว่าข้อมูลในคอลัมน์นั้นๆ คือหัวข้ออะไร
<tr>
  <th>รหัสนักเรียน</th>
  <th>ชื่อ-นามสกุล</th>
</tr>

ตัวอย่างการปฏิบัติ: การสร้างตารางข้อมูลพื้นฐาน ให้สังเกตการวางลำดับชั้นของแท็ก <table>, <tr>, <th> และ <td> ที่ซ้อนกันอย่างเป็นระบบ

<table border="1">
    <!-- แถวที่ 1 (ส่วนหัวตาราง) -->
    <tr>
        <th>รหัสนักเรียน</th>
        <th>ชื่อ-นามสกุล</th>
        <th>เกรดเฉลี่ย</th>
    </tr>
    <!-- แถวที่ 2 (ข้อมูลคนที่ 1) -->
    <tr>
        <td>66001</td>
        <td>สมชาย ใจดี</td>
        <td>3.50</td>
    </tr>
</table>

สรุปเนื้อหา: โครงสร้างตาราง (Table Structure)

  • <table> — กำหนดขอบเขตตาราง (โครงชั้นวางหนังสือ)
  • <tr> — สร้างแถวแนวนอน (ชั้นวางแต่ละชั้น)
  • <th> — ส่วนหัวตาราง ตัวหนา จัดกึ่งกลาง รองรับ Screen Reader
  • <td> — ช่องข้อมูลเนื้อหาทั่วไป (กล่องเก็บข้อมูล)

6.2 การจัดการเซลล์ขั้นสูง (Cell Spanning)

การยุบรวมพื้นที่เซลล์ (Cell Spanning) คือการเปลี่ยนตารางกริดธรรมดาให้เป็นโครงสร้างที่ตอบโจทย์การใช้งานจริง เปรียบเสมือนห้องคอนโดมาตรฐานที่แบ่งเป็นห้องเล็กๆ เท่ากันทุกห้อง แต่บางครั้งเราต้องการ "ทุบกำแพง" เพื่อรวมสองห้องเข้าด้วยกันให้กลายเป็นห้องนั่งเล่นขนาดใหญ่ หรือ "เจาะพื้นเพดาน" เพื่อสร้างบันไดเชื่อมสองชั้นแบบห้อง Duplex

6.2.1 colspan — การรวมเซลล์แนวนอน

colspan คือคำสั่งที่เปรียบเสมือนการ "ทุบกำแพงด้านข้าง" เพื่อขยายห้องออกไปในแนวนอน โดยจะขยายช่องข้อมูลให้กินพื้นที่ความกว้างเทียบเท่ากับ 2 ช่อง หรือมากกว่าในแถวเดียวกัน

<td colspan="2">ข้อความ</td>

ตัวอย่างผลลัพธ์: ช่อง "ยอดรวมราคาสินค้า" ถูกขยายให้กินพื้นที่ 2 คอลัมน์แทนที่จะมีแค่ 1 ช่องปกติ

ยอดรวมราคาสินค้าราคา
100200300

6.2.2 rowspan — การรวมเซลล์แนวตั้ง

rowspan คือคำสั่งที่เปรียบเสมือนการ "เจาะพื้นเพดาน" เพื่อสร้างห้อง Duplex ในแนวตั้ง โดยจะขยายช่องข้อมูลให้กินพื้นที่ทะลุลงไปยังแถว (Row) ด้านล่างที่อยู่ถัดไป

<td rowspan="3">ข้อความ</td>

ข้อควรระวัง: เมื่อใช้ rowspan แล้ว จะต้องลบโค้ด <td> ของช่องในแถวถัดไปที่โดนทับทิ้งเสมอ ไม่เช่นนั้นตารางจะเกิดการ "ล้นทะลัก" (Overflow) ผิดรูปทันที

6.2.3 กฎเหล็กป้องกันตารางล้นทะลัก (Table Overflow)

ผลรวมของจำนวนช่องในทุกแถว <tr> จะต้องมีค่าเท่ากันเป๊ะเสมอ โดยคำนวณได้จากสูตร:

จำนวนช่องรวมใน 1 แถว = (จำนวนแท็ก <td> ปกติ) + (ค่าตัวเลขใน colspan ของแถวนั้น)

กรณีตัวอย่างผลลัพธ์
ตัวอย่างที่ไม่ดี (Bad) colspan="3" + อีก 2 แท็ก <td> ปกติ รวมเป็น 5 ช่อง → ตารางล้นทะลัก ผิดรูป
ตัวอย่างที่ดี (Good) colspan="2" + อีก 1 แท็ก <td> ปกติ รวมเป็น 3 ช่อง → สมดุลพอดีกับแถวอื่น

6.2.4 นำไปใช้จริง: โครงสร้างตารางสอน

ตัวอย่างการผสานทั้งการทุบกำแพงแนวนอน (colspan) และเจาะพื้นแนวตั้ง (rowspan) ไว้ในตารางเดียวกัน สำหรับสร้างตารางสอนที่มีบางวันจัดกิจกรรมเต็มวัน และบางช่วงเรียนวิชาต่อเนื่องข้ามสองวัน

<tr>
  <th>วัน</th> <th>ช่วงเช้า</th> <th>ช่วงบ่าย</th>
</tr>
<tr>
  <td>วันจันทร์</td>
  <td colspan="2">กิจกรรมกีฬาสี (เต็มวัน)</td>
  <!-- ลบทิ้ง: ช่องที่ถูก colspan กินพื้นที่ไปแล้วห้ามเขียน td ซ้ำ -->
</tr>
<tr>
  <td rowspan="2">วันอังคาร - พุธ</td>
  <td>คณิตศาสตร์</td> <td>วิทยาศาสตร์</td>
</tr>

ผลลัพธ์ที่ได้:

วันช่วงเช้าช่วงบ่าย
วันจันทร์กิจกรรมกีฬาสี (เต็มวัน)
วันอังคาร - พุธคณิตศาสตร์วิทยาศาสตร์
ภาษาไทยสังคมศึกษา

สรุปเนื้อหา: การจัดการเซลล์ขั้นสูง

  • colspan (แนวนอน): รวมเซลล์ไปทางขวา เปรียบเสมือนการทุบกำแพงรวมห้องคอนโด
  • rowspan (แนวตั้ง): รวมเซลล์ลงด้านล่าง เปรียบเสมือนการเจาะพื้นทำห้อง Duplex
  • การรักษาสมดุล: ต้องลบโค้ด <td> ของช่องที่ถูกกินพื้นที่ทิ้งเสมอ เพื่อป้องกันตารางล้นทะลัก (Table Overflow)

6.3 การตกแต่งตารางด้วย CSS

ตาราง HTML ธรรมดาก่อนตกแต่งจะดูจืดชืด โบราณ และอ่านข้อมูลได้ยาก เปรียบเสมือนการนำแผ่นไม้ดิบๆ มาตอกตะปูประกอบกันเป็นชั้นวางของ โดยยังไม่ได้ขัดเงาหรือทาสี แต่ด้วยเวทมนตร์ของ CSS เราสามารถเสกให้ตารางข้อมูลดูเป็นมืออาชีพ ทันสมัย สะอาดตา คล้ายโปรแกรม Microsoft Excel ยุคใหม่ และสามารถโต้ตอบกับผู้ใช้งานได้อย่างมีชีวิตชีวา

6.3.1 เป้าหมายหลัก: เพื่อการกวาดสายตาที่รวดเร็วที่สุด

การนำเสนอข้อมูลแบบตารางที่ดีไม่ใช่แค่การพยายามยัดข้อมูลทุกอย่างลงไปในกรอบสี่เหลี่ยม แต่หัวใจสำคัญคือ "การออกแบบให้ผู้อ่านทำความเข้าใจข้อมูลได้เร็วที่สุด" โดยอาศัยหลักการ 3 ข้อประกอบกัน:

  1. เส้นแบ่งที่ชัดเจน (Borders): จัดกรอบให้ข้อมูลไม่ปะปนกัน
  2. ช่องไฟที่พอดี (Padding): สร้างพื้นที่หายใจให้ตัวอักษรไม่อึดอัด
  3. การชี้นำสายตา (Eye-tracking): ป้องกันไม่ให้ผู้อ่านหลงบรรทัดเมื่อมีข้อมูลจำนวนมาก

6.3.1.1 ลบรอยต่อกวนใจด้วย Border Collapse

โดยธรรมชาติ เมื่อเราสั่งตีเส้นขอบ เบราว์เซอร์จะสร้างเส้นขอบให้แต่ละช่องแยกจากกัน ทำให้เกิด "รอยต่อเส้นคู่" (Double Border) ที่ดูหนาเตอะและไม่สวยงาม คำสั่ง border-collapse: collapse; จะทำหน้าที่ "ยุบรวมเส้นขอบที่อยู่ติดกัน" ให้หลอมรวมกลายเป็นเส้นทึบเพียงเส้นเดียว ผลลัพธ์คือตารางที่คมกริบและดูสะอาดตา

table {
  border-collapse: collapse;
}

6.3.1.2 สร้างแถบไฮไลต์ชี้นำสายตาด้วย Hover Effect

เมื่อตารางมีข้อมูลยาวหลายสิบแถว ผู้ใช้งานมักเกิดอาการตาลาย การแก้ปัญหา UX ที่ยอดเยี่ยมที่สุดคือการทำ "เอฟเฟกต์ตอบสนองเมื่อเมาส์ชี้" เปรียบเสมือนการนำ "ไม้บรรทัดมาทาบใต้บรรทัด" เพื่อล็อกสายตาให้โฟกัสถูกจุด โดยใช้ซีเล็กเตอร์ :hover ร่วมกับแท็ก <tr>

tr:hover {
  background-color: #f1f1f1;
  cursor: pointer;
}

(คำอธิบาย: เมื่อเมาส์พาดผ่าน แถวนั้นจะเปลี่ยนเป็นสีเทาอ่อน และเมาส์จะเปลี่ยนเป็นรูปนิ้วชี้)

ตัวอย่างการเนรมิตตารางสรุปยอดขาย: รวมทั้ง border-collapse, padding และ hover effect เข้าไว้ด้วยกัน

table {
  width: 100%;
  border-collapse: collapse; /* ยุบเส้นขอบให้คมกริบ */
}
th, td {
  padding: 12px; /* ดันข้อความให้มีช่องไฟหายใจ */
  border: 1px solid #ddd;
}
th {
  background-color: #4CAF50; /* ทาสีเขียวเด่นเฉพาะหัวตาราง */
  color: white;
}
tr:hover {
  background-color: #f1f1f1; /* แถบไฮไลต์เมื่อเมาส์ชี้ */
}

ผลลัพธ์ (ลองเลื่อนเมาส์ไปชี้ที่แถวข้อมูลด้านล่างเพื่อดูเอฟเฟกต์ hover):

ลำดับชื่อสินค้ายอดขาย (บาท)
1เมล็ดกาแฟคั่วกลาง15,000
2ชาเขียวมัทฉะ8,500

ตัวอย่างเชิงโต้ตอบ: ลองนำเมาส์ไปวางบนแถวข้อมูล จะเห็นสีพื้นหลังเปลี่ยนเป็นสีเทาอ่อนตามคำสั่ง tr:hover

สรุปเนื้อหา: การตกแต่งตารางด้วย CSS

  1. ออกแบบเพื่อผู้อ่าน: เป้าหมายของการใช้ CSS ตกแต่งตาราง คือการทำให้ข้อมูลจำนวนมากสามารถกวาดสายตาอ่านได้ง่าย เป็นระเบียบ และไม่อึดอัด
  2. ขจัดเส้นขอบคู่: แก้ปัญหาตารางดูหนาและโบราณด้วยคำสั่ง border-collapse: collapse; เพื่อหลอมรวมเส้นขอบให้เป็นเส้นเดียวที่คมชัด
  3. UX ที่ดีด้วย Hover: ใช้ :hover ร่วมกับแท็ก <tr> เพื่อสร้างแถบสีไฮไลต์เวลานำเมาส์ไปชี้ ทำหน้าที่เหมือนไม้บรรทัดทาบสายตา ป้องกันผู้อ่านหลงบรรทัด
